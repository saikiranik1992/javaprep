Q003 CH 01 PDF Page 7 / 232

Is Java pass by value or pass by reference?

Interview Answer (20-Second Pitch)

Java is always pass by value. For an object, the copied value is its reference.

Source Example / Scenario 
static void change(List<String> p) {
    p.add("Kiran");           // Change shared object
    p = new ArrayList<>();   // Change local reference
}
List<String> names = new ArrayList<>();
change(names);
System.out.println(names);   // [Kiran]
Why It Works

p and names initially refer to the same list, so add changes that list. Assigning a new list to p changes only the method's local reference.

Common Interview Trap / Watch Out

Seeing a mutation in the caller does not imply pass by reference.
